# SecureDAL Evaluation

This directory contains the evaluation results and analysis for the [SecureDAL benchmarking process](../benchmarks/README.md).

```
evaluation/
├── final_results/
|   └── (results enhanced with p95 and p99 latency percentiles)
├── plots/
|   ├── data/
|   |   └── (generated data files for plots)
|   ├── plots/
|   |   └── (generated plots)
|   └── (plot generation scripts)
├── results/
|   └── (original pytest-benchmark generated results)
├── (histogram files generated by pytest-benchmark)
└── README.md
```


The prototype was evaluated under the following environment:

```markdown
- Linux-based 
- 8-core AMD EPYC14 Milan processor ~2.2 GHz
- 32 GB of memory
- 225 GB of available storage
- CPython 3.12.13
- UV 0.11.8
- Docker 29.4.1
- Apache OpenDAL 0.46.0 
- ipfshttpclient 0.7.0
- IPFS Kubo version: docker image ipfs/kubo:v0.41.0
- PostgreSQL version: docker image postgres:16
- Redis version: docker image redis:7.2
- MinIO S3 version: docker image minio/minio:RELEASE.2024-01-16T16-07-38Z
```

The original `pytest-benchmark`results are stored in the [`results`](./results) directory, and the results enhanced with *p95* and *p99* latency percentiles are stored in the [`final_results`](./final_results) directory.

Plot generation is performed at [`plots/run_plots.sh`](./plots/run_plots.sh) and the generated plots are stored in the [`plots/plots`](./plots/plots) directory.

To generate the plots, run the following commands:

```bash
# From the /evaluation directory
python ./plots/prepare_data.py

bash ./plots/run_plots.sh
```
